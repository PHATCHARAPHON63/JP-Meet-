# JP Meet

JP Meet ช่วยบันทึกเสียง ถอดเสียง และจัดทำรายงานการประชุม รองรับการเลือกประมวลผลในเครื่องหรือผ่านผู้ให้บริการออนไลน์ตามการตั้งค่า

## ดาวน์โหลดสำหรับ Mac M4

**[กดดาวน์โหลดตัวติดตั้ง JP Meet (.dmg)](https://github.com/PHATCHARAPHON63/JP-Meet-/releases/latest/download/JP_Meet_Mac_AppleSilicon.dmg)**

ลิงก์นี้ดาวน์โหลดไฟล์ `JP_Meet_Mac_AppleSilicon.dmg` ของรุ่นล่าสุดโดยตรง รองรับ Mac ที่ใช้ชิป M1, M2, M3, **M4** และใหม่กว่า รวมถึงรุ่น Pro และ Max

หากต้องการดูรายละเอียดรุ่น ให้เปิด[หน้ารุ่นล่าสุด](https://github.com/PHATCHARAPHON63/JP-Meet-/releases/latest) แล้วเลือกไฟล์ `.dmg` ในส่วน **Assets**

แอปยังไม่ได้รับการรับรอง notarization จาก Apple จึงอาจมีการแจ้งเตือนเมื่อเปิดครั้งแรก

## การติดตั้งบน Mac M4

1. [กดดาวน์โหลดไฟล์ `.dmg`](https://github.com/PHATCHARAPHON63/JP-Meet-/releases/latest/download/JP_Meet_Mac_AppleSilicon.dmg) แล้วเปิดไฟล์ที่ดาวน์โหลด
2. ลาก **JP Meet** ไปยังโฟลเดอร์ **Applications**
3. เปิด JP Meet จาก Applications

ภายในไฟล์ติดตั้งมี **INSTALLATION.txt** ซึ่งอ่านได้ก่อนเปิดแอป ดู[คู่มือติดตั้ง](INSTALLATION.txt) ได้บน GitHub ด้วย

## เมื่อ Apple แจ้ง “Apple could not verify …”

รุ่นนี้ยังไม่มี Developer ID และการรับรองจาก Apple หากคุณเชื่อถือไฟล์จากช่องทางนี้และต้องการอนุญาตให้เปิด JP Meet ให้ทำตามขั้นตอนต่อไปนี้:

1. ปิดข้อความเตือนด้วย **Done** หรือ **OK**
2. ไปที่ **System Settings → Privacy & Security**
3. เลื่อนลงไปที่ **Security** แล้วกด **Open Anyway** ตรงชื่อ **JP Meet**
4. ยืนยันด้วยรหัสผ่านเครื่องหรือ Touch ID หากระบบร้องขอ แล้วกด **Open**

หากไม่เห็นปุ่ม Open Anyway ให้ลองเปิด JP Meet จาก Applications อีกครั้ง แล้วกลับมาที่ Privacy & Security ดู[คำแนะนำของ Apple](https://support.apple.com/en-us/102445) การอนุญาตให้เปิดเป็นการตัดสินใจของผู้ใช้

## การอัปเดต

ติดตั้ง JP Meet จากตัวติดตั้งที่ตรงกับเครื่องของคุณ จากนั้นไปที่การตั้งค่าและเลือกตรวจอัปเดต เมื่อมีรุ่นใหม่ ให้หยุดบันทึกเสียง รอให้ระบบบันทึกข้อมูลเสร็จ แล้วเลือกดาวน์โหลดและติดตั้ง แอปจะเปิดใหม่หลังติดตั้ง

แอปตรวจลายเซ็นของไฟล์ก่อนติดตั้งอัปเดต ผู้ใช้ไม่ต้องมีสิทธิ์เข้าถึง repository ส่วนตัว และไม่ต้องกรอกรหัส GitHub ในแอป
