# JP Meet

JP Meet ช่วยบันทึกเสียง ถอดเสียง และจัดทำรายงานการประชุม รองรับการเลือกประมวลผลในเครื่องหรือผ่านผู้ให้บริการออนไลน์ตามการตั้งค่า

ดาวน์โหลด [JP Meet สำหรับ Mac Apple Silicon](https://github.com/PHATCHARAPHON63/JP-Meet-/releases/latest) รองรับ Mac ที่ใช้ชิป M1 และใหม่กว่า เลือกไฟล์ `.dmg` เพื่อติดตั้ง

แอปยังไม่ได้รับการรับรอง notarization จาก Apple จึงอาจมีการแจ้งเตือนเมื่อเปิดครั้งแรก

## การติดตั้งและอัปเดต

ติดตั้ง JP Meet จากตัวติดตั้งที่ตรงกับเครื่องของคุณ จากนั้นไปที่การตั้งค่าและเลือกตรวจอัปเดต เมื่อมีรุ่นใหม่ ให้หยุดบันทึกเสียง รอให้ระบบบันทึกข้อมูลเสร็จ แล้วเลือกดาวน์โหลดและติดตั้ง แอปจะเปิดใหม่หลังติดตั้ง

แอปตรวจลายเซ็นของไฟล์ก่อนติดตั้งอัปเดต ผู้ใช้ไม่ต้องมีสิทธิ์เข้าถึง repository ส่วนตัว และไม่ต้องกรอกรหัส GitHub ในแอป

## สิทธิ์และข้อมูลประชุม

อนุญาตการเข้าถึงไมโครโฟนและเสียงจากเครื่องตามที่ระบบร้องขอ เมื่อเลือกใช้ OpenAI เสียงและข้อความจะส่งไปยัง OpenAI และมีค่าใช้จ่าย API ตามบัญชีที่ตั้งไว้

repository นี้ใช้เผยแพร่ตัวติดตั้งและไฟล์อัปเดต โค้ดสำหรับพัฒนาอยู่ใน repository ส่วนตัวของผู้พัฒนา
