คู่มือติดตั้ง JP Meet สำหรับ Mac Apple Silicon

รองรับ Mac ที่ใช้ชิป M1, M2, M3, M4 และใหม่กว่า รวมถึงรุ่น Pro และ Max
ตัวติดตั้ง aarch64 ใช้กับ Mac M4 ได้โดยตรง

การติดตั้ง
1. กดลิงก์ดาวน์โหลดไฟล์ติดตั้งโดยตรง:
   https://github.com/PHATCHARAPHON63/JP-Meet-/releases/latest/download/JP_Meet_Mac_AppleSilicon.dmg
   ไฟล์ชื่อ JP_Meet_Mac_AppleSilicon.dmg รองรับ Mac M4
2. เปิดไฟล์ .dmg แล้วลาก JP Meet ไปยังโฟลเดอร์ Applications
3. เปิด JP Meet จาก Applications

เมื่อเปิดครั้งแรกแล้วพบข้อความ “Apple could not verify …”
รุ่นนี้ยังไม่มี Developer ID และการรับรอง notarization จาก Apple
คีย์ที่ลงนามไฟล์อัปเดตของ JP Meet ใช้ตรวจความถูกต้องของไฟล์ แต่ไม่ใช่การรับรองจาก Apple

หากคุณเชื่อถือไฟล์จากช่องทางเผยแพร่นี้และต้องการอนุญาตให้เปิดแอป:
1. ปิดข้อความเตือนด้วย Done หรือ OK
2. เปิด System Settings (การตั้งค่าระบบ)
3. เข้า Privacy & Security (ความเป็นส่วนตัวและความปลอดภัย)
4. เลื่อนลงไปที่ Security แล้วกด Open Anyway (เปิดต่อไป) ตรงชื่อ JP Meet
5. ยืนยันด้วยรหัสผ่านเครื่องหรือ Touch ID หากระบบร้องขอ แล้วกด Open (เปิด)

หากไม่เห็น Open Anyway ให้ลองเปิด JP Meet จาก Applications อีกครั้ง แล้วกลับมาที่ Privacy & Security
การอนุญาตนี้เป็นการตัดสินใจของผู้ใช้สำหรับแอปนี้ คู่มือไม่ได้เปลี่ยนการตั้งค่าความปลอดภัยให้โดยอัตโนมัติ
คำแนะนำจาก Apple: https://support.apple.com/en-us/102445

เมื่อเริ่มใช้งาน
อนุญาตสิทธิ์ไมโครโฟนและการบันทึกเสียงจากเครื่องตามที่ macOS ร้องขอ
หากใช้แอปรุ่นเดิม ควรสำรองข้อมูลประชุมก่อนติดตั้ง

การอัปเดต
เปิดการตั้งค่าใน JP Meet แล้วเลือกตรวจอัปเดต เมื่อมีรุ่นใหม่ ให้หยุดบันทึกเสียงและรอให้บันทึกข้อมูลเสร็จก่อนติดตั้ง
แอปจะเปิดใหม่หลังติดตั้ง ผู้ใช้ไม่ต้องกรอกรหัส GitHub เพื่อรับอัปเดต
